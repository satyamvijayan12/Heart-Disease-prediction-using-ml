# Heart Disease Prediction using Machine Learning

## Overview
This project aims to predict the presence of heart disease in patients using various machine learning algorithms on different datasets. The goal is to assist medical professionals in diagnosing heart disease quickly and accurately.

## Features
- Predicts the likelihood of heart disease using patient data.
- Implements several machine learning algorithms, such as Logistic Regression, Decision Trees, and Support Vector Machines.
- Visualizes data using various graphs to enhance understanding.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
